# Amazon Clone 🛒

A static front-end clone of Amazon's homepage, built using only HTML and CSS to practice web layout and styling fundamentals.

## Features
- 🖼️ Amazon-style homepage layout (header, nav bar, banner, product grid)
- 🎨 Custom CSS styling to match Amazon's look and feel
- 📱 Responsive design using media queries
- 🧱 Flexbox/Grid-based layout structure

## Tech Stack
- **HTML5**
- **CSS3** (Flexbox / Grid)

## Getting Started

### Installation
```bash
git clone https://github.com/username/amazon-clone.git
cd amazon-clone
```

### Run the project
Just open `index.html` in your browser — no build steps or dependencies required.
